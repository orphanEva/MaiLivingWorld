# 长期伴侣模式与验收

后续产品方向是长期 AI 伴侣：同一个持续存在的角色、唯一主人、自己的兴趣与看法、能续接的共同经历，以及自然而有分寸的亲密表达。QQ群、私聊和外部平台都是同一个心智的信息窗口；来源与表达权限仍保留，不把群友的私事当成主人的关系素材。

v0.15.0 补上了明确的相处约定、纪念日与回忆账本、伴侣风格和真实时段提示。兴趣与观点继续由已有成长系统从证据中逐步形成，不把用户喜欢的东西直接当成她自己的喜好。没有关系积分、连续签到或因缺席扣分。

## 启用

先备份现有数据，再安装新 ZIP。不要用默认模板覆盖自己的数据库、QQ 与 MCP 配置。在现有配置中调整这些字段：

```toml
[owner]
enabled = true
# qq 沿用已绑定的主人 QQ；不要复制占位号码。
relationship_enabled = true
relationship_mode = "partner"

[unified_mind]
enabled = true
mode = "active"

[bond]
enabled = true
daily_rhythm = true
```

默认的 `brain_memory.include_owner=true` 让可信主人私聊进入统一上下文。若此前主动关闭了该项，需要在自己的输入名单中允许主人，否则读取工具与联想没有当前消息上下文。相处命令仍独立核验真实私聊发送者。

`owner.private_template` 非空时仍优先作为基础风格；已确认的禁用称呼和停止亲昵高于基础风格。`partner` 也不强制改掉麦麦原来的核心性格。旧版配置的 `banter` 不会在升级时悄悄改成伴侣。

兴趣与性格的持续学习另需开启已有 `[growth] enabled=true, mode="active"`，并保留真实消息或工具来源供它学习。阅读、共同计划、主动联系沿用各自开关。新增 `[bond]` 不会打开主动消息、联网、下载或额外模型调用；关系命令会持久写入，和阅读/计划一样不依赖主动聊天的 `general.dry_run`。

## 私聊中使用

必须是绑定主人本人发出的完整私聊消息。群聊、自称主人、转发组件、引述片段和模型工具参数均不能更改约定。

| 发送内容 | 效果 |
| --- | --- |
| `以后叫我小明吧` 或 `/相处 称呼 小明` | 保存日常称呼，换会话与重启后继续使用 |
| `别叫我主人` 或 `/相处 不叫 主人` | 禁用该称呼；绑定身份仍不变 |
| `/相处 称呼 默认` | 清除自定义称呼，回到配置中未被禁用的称呼 |
| `不要撒娇` 或 `/相处 亲昵 暂停` | 立即停止撒娇、暧昧和亲昵称呼，正常关心仍保留 |
| `/相处 亲昵 自然` | 允许自然亲昵，不要求每轮表达爱意 |
| `/相处 亲昵 默认` | 遵循已有关系风格 |
| `/相处 边界 不要拿我的旧昵称开玩笑` | 保存一条明确相处边界，仅用于私人表达 |
| `/相处 记住 我们约好周末讨论这本小说` | 保存主人自己留下的回忆，不自动创建提醒或把约定标成完成 |
| `/相处 纪念日 2026-11-05 初次相识` | 保存完整日期；当天聊天时可被联想，不主动群发祝福 |
| `/相处 删除边界 <边界key>` | 明确移除一条边界 |
| `/相处 忘记 <回忆ID> <当前版本>` | 停用回忆及其派生来源，保留变更审计 |

可问“看看我们保存的相处约定和回忆”，让 AI 使用只读 `living_world_relationship` 获取当前版本、边界 key 与回忆 ID。该工具可按 `query` 搜索、`offset` 翻页，每页最多 20 条；不能代主人确认或删除。普通长句暂不会自动变成长期约定，避免把玩笑、讨论或转述误写成承诺。称呼最多 24 字、边界 120 字、回忆 400 字；最多 20 个禁用称呼、20 条边界、200 条有效回忆。达到上限保留原数据，需要先明确删除旧项。

回忆仍标为主人自述。她可以说“你之前记下过……”，不能据此虚构自己亲身经历过线下约会。原始记录和派生结论经过统一表达判断，私聊回忆不直接进入群聊回复。遗忘指停用当前回忆、使相关引用失效，不抹去备份或审计历史。

纪念日只按配置时区和明确年月日匹配，不猜模糊日期，不自动把二月二十九日挪到二月二十八日。时段提示帮助语气自然，不推断你刚起床、在工作或该睡觉，也不虚构她吃饭、出门等线下生活。

## 实际验收

1. 私聊改称呼，切到新会话并重启容器，确认仍自然使用；再次说“别叫我主人”，不再把它当口癖。
2. 在伴侣风格下说“不要撒娇”，确认下一轮恢复正常聊天，不要求解释或反复确认。
3. 记下一件小事，隔天以相关话题提起；确认来源正确、不编造细节。用忘记命令停用后，再问时不能继续拿它当事实。
4. 群里与同一主人聊天，确认熟悉但不泄露私人昵称、约定或回忆；其他群友不能冒认主人。
5. 结合既有阅读和成长功能，看她是否能说出有依据的兴趣与不同看法，而不是复述“偏好强度+0.20”。
6. 保持几天不聊天后回来，不出现关系降级、指责或要求补偿；连续性来自保存的经历。
7. 查看管理面板的相处与回忆区域；做空目录备份恢复演练，确认原身份和约定还在。参见 [备份说明](BACKUP.md)。

自动化测试验证权限、状态连续性、来源失效和提示输入。实际聊天自然程度、MaiBot 容器兼容及模型表现，需要以上真实 QQ 对话验收。
